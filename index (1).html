GET /api/v2/users ✓ Verified Live

Retrieves a paginated list of user objects with filtering and sorting parameters.

Query Parameters
ParameterTypeDescription
pageintegerPage number for pagination. Default: 1
limitintegerNumber of items per page (Max: 100). Default: 20
statusstringFilter by user state: active, pending, suspended
Response Example (HTTP 200 OK)
{
  "status": "success",
  "data": [
    {
      "id": "usr_9012a8f",
      "email": "m.manyuele@example.com",
      "full_name": "Mark Lemayian Manyuele",
      "status": "active",
      "created_at": "2026-08-15T09:30:00Z"
    }
  ],
  "pagination": {
    "current_page": 1,
    "total_pages": 12,
    "total_records": 240
  }
}
POST /api/v2/users ✓ Verified Live

Creates a new user profile. Requires Bearer token authentication.

Request Body (application/json)
FieldTypeDescription
email *requiredstringValid RFC-5322 email address.
full_name *requiredstringUser legal full name.
rolestringUser system role: analyst, admin. Default: analyst
Response Example (HTTP 201 Created)
{
  "status": "created",
  "data": {
    "id": "usr_3341b2c",
    "email": "m.manyuele@example.com",
    "full_name": "Mark Lemayian Manyuele",
    "role": "analyst",
    "created_at": "2026-10-13T10:45:00Z"
  }
}
